# Paradise Nursery

Paradise Nursery is a React-based e-commerce web application for purchasing indoor and outdoor plants. The application allows users to browse plants by category, add items to a shopping cart, and manage their orders through an interactive user interface.

## Features

* Landing page with nursery introduction
* Product listing page displaying various plants
* Plants organized by categories
* Shopping cart functionality
* Add and remove plants from cart
* Update item quantities in cart
* Display total number of items in cart
* Display total cost of items
* Responsive user interface built with React

## Technologies Used

* React
* JavaScript (ES6+)
* HTML5
* CSS3
* React Router
* Redux (if implemented)

## Installation

1. Clone the repository:

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/Paradise-Nursery.git
```

2. Navigate to the project directory:

```bash
cd Paradise-Nursery
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm start
```

The application will run at:

```text
http://localhost:3000
```
